Even Odd Checker

About

This is a simple HTML and JavaScript project. I made this project to practice taking a number from an input field and checking whether the number is even or odd using JavaScript.

The webpage contains an input field where the user can enter a number and a button to check the number. The result is displayed in the console.

Technologies Used

HTML5

JavaScript

Features

Added an input field for entering a number

Added a button to check the number

Used JavaScript to check whether the number is even or odd

Used the remainder operator to check the number

Displayed the result using console.log()

Some basic JavaScript concepts used in this project are:

How to Run

Keep index.html, check.js and style.css in the same folder.

Open index.html in any browser.

Enter a number in the input field.

Click the Check button.

Open the browser console to see whether the number is even or odd.
